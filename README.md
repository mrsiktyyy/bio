# Phoenix Team — redesigned bio

Полностью переработанный frontend:
- единый CSS и JS вместо повторяющихся inline-блоков;
- iPhone/glassmorphism интерфейс;
- сиренево-фиолетовый фон + мягкий голубой акцент;
- верхняя адаптивная навигация;
- плавный индикатор активной страницы;
- переходы между страницами;

- адаптив для телефона.

Существующие изображения из репозитория используются по исходным путям `/phx/`, `/posts/` и из корня проекта.
